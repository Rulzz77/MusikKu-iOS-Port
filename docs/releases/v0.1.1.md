# MusikKu iOS 0.1.1 (Build 2)

**Status:** development build — not a signed or published release  
**Version source:** `ios/Support/Info.plist`  
**Merged changes:** PR #2 (CI validation and simulator smoke-check fixes)

## Changes

- Bumped the application marketing version to 0.1.1 and build number to 2.
- Run source Info.plist, AppIcon catalog, Privacy Manifest and bundled license validation before XcodeGen generates the project.
- Configure the AppIcon build setting for the generated Xcode project.
- Remove a simulator-only Info.plist assertion that produced a false negative despite the source AppIcon metadata and compiled asset catalog being present.
- Preserve the app-bundle checks for Privacy Manifest, compiled asset catalog and bundled legal notices.

## Validation

The earlier run #178 successfully built the InnerTubeX XCFramework, generated the Xcode project, compiled the iOS Simulator target and passed all unit tests. It stopped at the simulator bundle's `CFBundleIconName` assertion before the launch smoke test could execute.

The corrected pipeline is being validated on main by [GitHub Actions run #181](https://github.com/Rulzz77/MusikKu-iOS-Port/actions/runs/46030938381). Do not treat this development update as fully CI-verified until that run completes successfully and its artifacts are available.

## Not included

- No signed IPA, TestFlight distribution, App Store submission or GitHub Release.
- Physical iPhone playback, background audio and lock-screen behaviour remain unverified.
